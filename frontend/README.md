# Angular 14 Frontend

Create the Angular 14 application in this folder:

```bash
npm install -g @angular/cli@14
ng new staffing-invoice-ui --routing --style=scss
cd staffing-invoice-ui
ng add @angular/material
```

Replace `src/app` with the starter files in `frontend/starter` or use the API contract below.
Run the API at https://localhost:7181 and Angular at http://localhost:4200.

API base URL: `https://localhost:7181/api`

This delivery includes a working .NET solution and API. The Angular folder provides the UI implementation blueprint and API integration contract; it is intentionally kept separate so the UI can be generated with the Angular 14 CLI version installed in your environment.
